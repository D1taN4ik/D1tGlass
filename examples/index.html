refract.js

Add glass to any element with a single attribute. Size, position and border radius come from the element's own styles. Support in this browser: 

<script src="refract.js"></script>

<header class="my-nav" data-refract>...</header>

Buttons

data-rf-press — springy press, data-rf-haptic — haptic feedback.

<button class="btn" data-refract data-rf-press data-rf-haptic data-rf-tint="dark">
  Dark
</button>

Card

Card with stronger refraction

Attributes data-rf-scale="70" data-rf-bezel="28". Works with any border-radius, including percentages.

Dynamic elements

Elements added later (modals, toasts, AJAX content) are picked up automatically via MutationObserver.

Drag the lens and tweak the options. The sliders simply change data-rf-* attributes.

JS API

Refract.apply('.card', { scale: 60, aberration: 0.12 });
Refract.remove(el);
Refract.refresh(el);          // after changing border-radius
const t = Refract.tabs(nav);  // t.index, t.select(2)
Refract.haptic(10);
Refract.supported;            // true in Chromium

nav.addEventListener('rf:change', e => console.log(e.detail.index));
